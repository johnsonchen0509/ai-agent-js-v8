## 作業 1：台灣夜市小吃達人

本分支從 `1.4-openai-api-with-memory` 開始，將系統角色改為「台灣夜市小吃達人阿夜」。
角色設定包含走訪台灣夜市的背景、熱情親切且具體實用的說話風格，以及夜市小吃、攤位類型、飲食限制與逛吃路線的專業領域。
對話內容會透過 lowdb 寫入 `.history`，所以程式在同一次執行中會保留前面每一輪的內容。

### 五輪對話紀錄

以下是測試時的連續五輪對話，第二輪之後仍能接續第一輪提到的城市與預算：

1. **使用者：** 我週末要去台南，兩個人每人預算 300 元，想吃在地特色。
	**阿夜：** 建議先從牛肉湯或蝦仁飯開始，再分食棺材板；兩人可以把主食控制在 200 元左右，留預算給甜點或飲料。
2. **使用者：** 我不吃牛肉，還是想要有熱食，該怎麼調整？
	**阿夜：** 記得你們是在台南、每人 300 元，而且不吃牛肉。可以改吃蝦仁飯或棺材板，向攤商確認內餡與高湯沒有牛肉，再搭配一份小吃。
3. **使用者：** 那我們想安排一條一小時的路線，不要吃太油。
	**阿夜：** 延續你們不吃牛肉的條件，可以先吃蝦仁飯，再選清爽小份小吃，最後用水果或茶收尾；每站留 15 到 20 分鐘，避免炸物集中在同一段。
4. **使用者：** 如果同行的人想吃甜的，你推薦什麼？
	**阿夜：** 在原本的台南路線最後加入一份甜食即可，建議兩人分食，並選水果或茶飲搭配，這樣比較不會超過每人 300 元。
5. **使用者：** 幫我把今天的重點整理成清單。
	**阿夜：** 今天的條件是台南、兩人、每人 300 元、不吃牛肉、避免太油，路線以蝦仁飯或棺材板等熱食開場，搭配小份小吃，最後以甜食或水果茶收尾。

## 作業 2：Function Calling 工具

新增 `tools/night-market.js` 的 `recommend_night_market_food` 工具。它接收城市、想吃的類型與飲食限制，回傳小吃建議、逛吃順序與飲食注意事項；`main.js` 會在模型產生 function call 時執行工具，再把結果交回模型整理成回答。

可測試的提問例子：

```text
我想去台北夜市，喜歡鹹食，吃全素，請推薦適合的方向。
```
